# Story elements: 150 parts of an engaging story, adapted for Knowledge Guardians

Mika shared a list of 150 elements that make an RPG story engaging for every player type, age and play style (2026-11-26). This file adapts each element to this game: a TOK game for school, with no combat, no runtime AI, no gambling, no romance, and real care for cultures. Read it with [STORY_BIBLE.md](STORY_BIBLE.md). The conflict map is in section 15 of the story bible.

**How to use this file.** Before you add a scene, a quest or a system, find the elements it serves. When you build one that is marked ◐ or ○, change the mark and name the file.

**Marks:** ✓ in the game now · ◐ partly in the game · ○ planned (not built).

**Adaptation rules (apply to every element):**

- "Combat" in the list means **argument, investigation and checking** here: Showdowns, Fray creatures named as errors of reasoning, seals and puzzles. Nobody is hurt.
- "Power" and "levelling up" mean **better ways of knowing**: tools, Lens views, talents and Insight.
- "Romance" (element 36) is **not used**. Deep bonds are platonic: friendship, mentorship, found family.
- Myths, prophecies and patrons are **invented and in-world**. No real religion's God or sacred figures are an opponent. Real belief is a TOK lens (religious knowledge systems), treated with respect.
- Every element must also teach or show a TOK idea, played and not told.
