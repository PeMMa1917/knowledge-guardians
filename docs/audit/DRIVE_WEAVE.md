# Ideas from Mika's lesson folder

Mika's lesson folder holds TOK lessons, card games and activities. This file lists the **ideas** and where they go in the story. It holds no handout wording, no student work and no IB documents, because this repository is public.

Rules for every item:
- It becomes part of the one storyline. The player is a knowledge guardian, and the activity happens to someone in the world.
- It must not feel like a quiz, flashcards, an essay or homework.
- No crime (a mystery is an audit or a lost-property case), no betting, friendships only. A god as an opponent is always invented; real faiths appear only with respect and sources (AGENTS.md story bible rule, X-006).
- Real peoples' knowledge is included and verified with reliable sources, best from the people themselves (decision X-006). Each people is separate.

Status: **in game** (already woven), **planned** (has a place), **idea** (needs a place).
